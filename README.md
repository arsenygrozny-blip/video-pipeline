# Видео-конвейер: Telegram-бот на Render + рендер на Kaggle

Схема работы:

```
Telegram  →  бот на Render (main.py)  →  Kaggle Kernel (worker.py)  →  готовое видео в Telegram
             диалог, задание,            ffmpeg + whisper large-v3,
             кнопки, отмена               нарезка 9:16, субтитры, рендер
```

Рендер целиком уходит на Kaggle, твой телефон ничего не считает — только переписка с ботом.

## Файлы

- `main.py` — бот, живёт на Render. Общается с тобой в Telegram, собирает задание и запускает кернел на Kaggle.
- `worker.py` — код, который выполняется на Kaggle. Скачивает озвучку и фоны, распознаёт речь, рисует субтитры, баннер, обложку и собирает видео.
- `render.yaml` — описание сервиса для Render (Blueprint, деплой в пару кликов).
- `selftest.py` — проверка рендера локально, без Telegram и без Kaggle.
- `requirements.txt` — зависимости для Render.

## Что нужно один раз завести

1. **Kaggle**: аккаунт с **подтверждённым телефоном** (без него не дадут GPU и интернет).
   Settings → API → *Create New Token* → скачается `kaggle.json` (внутри `username` и `key`).
2. **Telegram**: бот у `@BotFather` → токен. Свой числовой ID — у `@userinfobot`.
3. **GitHub**: аккаунт (Render деплоит код из Git).
4. **Render**: аккаунт (free-плана хватает).

## Деплой

1. Залей эту папку в **приватный** репозиторий на GitHub.
2. В Render: **New → Blueprint** → выбери репозиторий. Render прочитает `render.yaml` и попросит вписать:
   - `BOT_TOKEN` — из BotFather;
   - `ALLOWED_USER_ID` — твой номер из `@userinfobot`;
   - `KAGGLE_USERNAME` — из `kaggle.json`;
   - `KAGGLE_KEY` — из `kaggle.json`;
   - `COOKIES_TXT` — можно оставить пустым (см. раздел про YouTube).
3. **Apply / Deploy**. Через минуту пиши боту `/start`.

Кернел `твой_ник/video-worker` создаётся на Kaggle автоматически при первом задании — заранее ничего делать не надо.

## Как пользоваться ботом

- `/start` → **🎬 Новое видео**
- 1/4 — озвучка: **ссылка** или **файл** (аудио/голосовое/видео/документ, до 20 МБ)
- 2/4 — фоны: ссылки **или файлы** (одна/один или несколько, склеятся по порядку) → **✅ Готово**
- 3/4 — баннер файлом (mp4/gif/webm) или **⏭ Пропустить**
- 4/4 — текст обложки или **⏭ Пропустить**
- на экране «Всё готово» можно переключить **стиль субтитров** кнопками, затем **🚀 Создать**
- дальше в чате идут статусы: скачивание, распознавание, сборка, отправка.

Источники (озвучку и фоны) можно смешивать: часть ссылками, часть файлами.

Кнопка **🛑 Отменить** останавливает задание (и мягко, и через Kaggle API).
Команда `/status` показывает, что сейчас происходит на Kaggle.

## Настройки (Render → Environment)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `KERNEL_SLUG` | `video-worker` | имя ядра на Kaggle |
| `WHISPER_MODEL` | `large-v3` | точность распознавания. `small` / `distil-large-v3` — быстрее |
| `WHISPER_MODEL_CPU` | `small` | модель, если GPU не завёлся |
| `WHISPER_LANG` | `ru` | пусто = определять язык автоматически |
| `WHISPER_DEVICE` | `auto` | `auto` / `cuda` / `cpu` |
| `X264_PRESET` | `veryfast` | `ultrafast` = сборка быстрее, картинка хуже |
| `STYLE` | `classic` | стиль субтитров по умолчанию (`classic`/`shorts`/`neon`/`lime`/`minimal`) |
| `JOB_TIMEOUT_MIN` | `45` | предохранитель: через сколько минут задание убивается |

## Стили субтитров

На экране «Всё готово» есть кнопки стилей — переключаются на лету, до нажатия «Создать»:

| Ключ | Название | Как выглядит |
|---|---|---|
| `classic` | Классика | белые субтитры снизу, по 3 слова, с обводкой |
| `shorts` | Shorts | крупно, слово за словом, по центру кадра |
| `neon` | Неон | жёлтый текст с толстой обводкой |
| `lime` | Лайм | зелёный текст с обводкой |
| `minimal` | Минимал | мельче, по 4 слова, без капса, снизу |

Стиль по умолчанию задаётся переменной `STYLE` на Render (`classic`, если не задана).
Сами пресеты (шрифт, цвет, размер, положение, число слов) — в `worker.py` в словаре `SUB_STYLES`; можно добавлять свои ключи, но не забудь продублировать их в списке `STYLES` в `main.py`.
Тонкая настройка шрифта/баннера/надписи «подпишись»/обложки — в блоках `SUB`, `BANNER`, `SUBSCRIBE`, `COVER` в начале `worker.py`.

## Лимиты и подводные камни

- **Kaggle GPU — 30 часов в неделю** на аккаунт, одна сессия до 12 часов.
- **Одно задание за раз**: пока кернел считает, второе не запустится (бот честно скажет подождать).
- **Telegram**: готовое видео до 50 МБ — битрейт подбирается автоматически под ~45 МБ. Файлы, которые *ты* шлёшь боту (озвучка, фоны, баннер), — **до 20 МБ**: столько Telegram даёт ботам скачивать через Bot API. Больше — присылай ссылкой.
- **Render free** засыпает после ~15 минут простоя: первое сообщение после сна разбудит сервис за 30–60 секунд.
- **YouTube** может требовать авторизацию с серверных IP. Если скачивание падает с `403`/«Sign in to confirm you're not a bot» — выгрузи cookies браузера в формате Netscape и вставь их текстом в переменную `COOKIES_TXT` на Render.
- **ffmpeg на Kaggle**: воркер проверяет, умеет ли ffmpeg рисовать субтитры (libass), и если нет — сам ставит apt-версию. Conda-шный ffmpeg из образа Kaggle libass не умеет, из-за этого субтитры молча пропадали.
- **whisper и PyAV**: `faster-whisper` внутри зовёт `av.open(..., metadata_errors=...)`, а сборка `av` в образе Kaggle такого аргумента не знает и падает с `TypeError`. Поэтому воркер декодирует звук сам через ffmpeg (`load_audio`) и отдаёт в модель массив — от PyAV ничего не зависит.
- **Первый запуск** дольше обычного: Kaggle поднимает машину, качает модель whisper large-v3 (~3 ГБ).

## Проверка рендера без Telegram и Kaggle

```bash
python3 selftest.py
```

Скрипт прогоняет настоящий код из `worker.py` на локальных тестовых файлах: нарезка 9:16, склейка двух фонов, вшивание субтитров, баннер, обложка, смена стиля (`shorts` — субтитры уезжают в центр) и сборка из **файловых** источников (озвучка/фоны как файлы Telegram, а не ссылки). На выходе — папка с `result.mp4` и отчёт из галочек.
